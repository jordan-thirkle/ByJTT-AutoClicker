# Security Policy

## Supported versions

The latest version on the default branch is supported with best-effort fixes.

## Reporting a vulnerability

If you discover a security issue, please avoid posting exploit details publicly before a fix is available. Report it privately to the maintainer via GitHub (e.g. a private security advisory or direct contact, if available) with:

- A description of the issue and potential impact
- Steps to reproduce or proof of concept
- Affected version/commit and environment details

## Scope and responsible use

ByJTT AutoClicker is a local Windows automation utility. It does not include network services, telemetry, or remote control features. Users are responsible for complying with applicable laws and third-party terms when using automation tools.
